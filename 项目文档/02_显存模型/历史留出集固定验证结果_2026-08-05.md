# 历史留出集固定验证结果

日期：`2026-08-05`

状态：`已使用原历史留出集重新验证；留出观测未参与任何拟合；M1 仍不可发布`

## 1. 这次修正了什么

上一版迁移实验把 `325` 条严格历史观测全部作为校准证据使用，因此只能回答“老数据加入训练后，交叉验证表现如何”，不能再把其中原来的历史留出部分解释成独立验证。

本次恢复历史数据原始角色：

| 数据部分 | 原始观测数 | 本次用途 |
|---|---:|---|
| 当前 19 个数据源 | 105 | 参与拟合；按数据源轮流留出验证 |
| 原历史训练/校准集 | 158 | 参与 M1 拟合 |
| 原历史留出集 | 167 | **完全不参与拟合，只做一次固定验证** |
| 无精确实验绑定的 legacy 记录 | 594 | 继续排除 |

固定留出集没有参与：

- 模型选择；
- 中心回归系数拟合；
- 残差上界和显存膨胀系数计算；
- OOM 防护规则计算；
- 超参数选择。

M1 模型结构在查看固定留出结果之前已经确定。

| 历史固定留出原始观测 | 167 条 |
| 历史固定留出去重后配置/结果组 | 106 组 |
| 训练与留出 observation ID 重复 | 0 |
| 历史训练与留出配置/结果组重复 | 0 |

需要注意：历史训练集与历史留出集来自同一组历史派生数据集。这 5 个数据集内部存在内容连接，因此它们共同只算 `1` 个历史数据源。固定留出集在“观测和实验配置”层面完全隔离，但不是一个新采集的、数据源完全独立的前瞻验证集。

## 3. 历史固定留出集效果

167 条留出观测去重后是 `106` 个配置/结果组，其中成功 `74` 组、OOM `32` 组。

这里同时比较：

- 只使用当前 105 条观测拟合；
- 使用当前 105 条加历史训练 158 条拟合。

| 历史固定留出指标 | 只用当前数据拟合 | 加入历史训练数据拟合 | 变化 |
|---|---:|---:|---:|
| 已分配显存误差 | 26.40% | **19.70%** | 改善 6.70 个百分点 |
| 预留显存误差 | 34.55% | **23.08%** | 改善 11.47 个百分点 |
| 显存上界覆盖率 | 95.95% | **100%** | 改善 4.05 个百分点 |
| 安全配置放行率 | 54.93% | 32.39% | 下降 22.54 个百分点 |
| 错误放行的不安全成功配置 | 2 | **0** | 消除 2 个 |
| 错误放行的 OOM 配置 | 4 | **0** | 消除 4 个 |

历史训练数据带来的效果非常明确：

1. 在未参与拟合的历史配置上，显存中心值误差明显下降；
2. 上界覆盖率达到 100%；
3. 原来 6 个错误放行全部消除；
4. 代价是模型明显更保守，安全配置放行率从 54.93% 降到 32.39%。

所以不能只说“总体效果变好了”。更准确的结论是：**历史数据显著改善了历史分布上的误差和安全性，但当前安全余量过大，降低了可用性。**

## 4. 当前验证与历史留出合并后的总体效果

总体汇总由两部分组成：

```text
当前 19 个数据源的按源留出预测
                    +
从未参与拟合的历史固定留出预测
                    ↓
193 个验证配置/结果组，20 个来源组
```

193 组中成功 `154` 组、OOM `39` 组。历史派生数据仍只按 `1` 个来源组计权，避免因为历史重复实验较多而压过当前 19 个业务源。

| 总体指标 | 只用当前数据拟合 | 加入历史训练数据拟合 | 变化 |
|---|---:|---:|---:|
| 已分配显存误差（按来源等权） | 6.05% | **5.58%** | 改善 0.47 个百分点 |
| 预留显存误差（按来源等权） | 16.38% | **16.36%** | 基本不变 |
| 显存上界覆盖率（按来源等权） | 98.80% | **100%** | 改善 1.20 个百分点 |
| 安全配置放行率 | 63.19% | 52.08% | 下降 11.11 个百分点 |
| 错误放行的不安全成功配置 | 2 | **0** | 消除 2 个 |
| 错误放行的 OOM 配置 | 4 | **0** | 消除 4 个 |

总体结果同样说明：中心误差小幅改善，安全性明显改善，但放行策略过于保守。

## 5. 当前关键 LoRA 范围

当前候选模型的正式适用范围仍是：

```text
H800 + LoRA + ZeRO-2 + 关闭梯度检查点 + 2 卡 + 非 Packing
```

当前 19 个数据源在该范围内的按源留出结果：

| 指标 | 只用当前数据拟合 | 加入历史训练数据拟合 |
|---|---:|---:|
| 验证配置数 | 53 | 53 |
| 已分配显存误差 | 5.29% | 5.26% |
| 预留显存误差 | 20.68% | 20.40% |
| 显存上界覆盖率 | 100% | 100% |
| 安全配置放行率 | 78.05% | 78.05% |
| 错误放行 | 0 | 0 |

历史固定留出集中只有 `4` 个配置落入这个关键 LoRA 范围，其中成功 `2` 个、OOM `2` 个。该小样本上的预留显存误差为 `3.72%`、上界覆盖率为 `100%`、错误放行为 `0`，但两个安全成功配置都没有被放行。因此这 4 个配置只能作为补充证据，不能代替新的关键 LoRA 独立数据源。

## 6. 最终判断

本次固定留出验证证明：

- 老数据确实参与了拟合，但只使用原历史训练部分 `158` 条；
- 原历史留出 `167` 条完全没有参与拟合；
- 加入历史训练数据后，历史留出上的已分配和预留显存误差分别改善约 `6.70` 和 `11.47` 个百分点；
- 总体错误放行从 `6` 个降为 `0`；
- 但是总体安全配置放行率从 `63.19%` 降到 `52.08%`，模型明显过于保守；
- 当前关键 LoRA 放行率仍为 `78.05%`，没有达到 `90%` 目标；
- 固定历史留出不是全新来源，仍不能替代第二阶段新数据源实验。

因此 M1 继续保持影子候选状态，生产模型不变。第二阶段 20 个新独立数据源、60 个作业仍然需要执行，重点应放在校准安全上界、减少不必要拒绝，而不是继续提高保守程度。
