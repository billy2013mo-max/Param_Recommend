# 统一资源实验停止与部分重拟合记录（2026-08-09）

## 1. 本次结论

统一资源实验已停止，8 张 H800 均已释放。本次停止前完成 186 / 220 个作业，保留了 152 个成功结果和 34 个 OOM 结果；未完成的 34 个作业没有作为成功或 OOM 样本进入拟合。

使用当前可用数据完成了显存中心模型和吞吐模型的分析性重拟合。两者均为影子模型，没有覆盖生产模型，也没有生成可发布的推荐器配置。

结论如下：

1. 显存中心模型从本轮数据中获得了真实但有限的收益：在既有严格跨来源诊断集上，同一模型族从只用旧数据时的 12.69% 降至 11.59%，改善 1.11 个百分点。
2. 该显存模型在嵌套留一来源交叉验证中的来源等权 MAPE 仍为 15.36%，P90 绝对百分比误差为 33.76%，尚未达到可替换当前模型的水平。
3. OOM 右删失约束总体满足率为 87.67%，但 1 卡组仅为 45.45%。这说明当前问题不只是中心误差，低估风险也没有稳定控制住。
4. 吞吐模型在旧 H800 留出集上的平均误差基本不变，P90 有改善；但未见模型和未见数据集验证变差，因此同样不应发布。

## 3. 显存重拟合的数据口径

### 3.1 观测定义

显存成功样本提供中心标签，即单卡 CUDA reserved memory 峰值。OOM 样本不提供真实峰值，只能说明真实需求超过设备可用容量，因此按右删失观测（right-censored observation）处理：

\[
M_{\mathrm{true}}>M_{\mathrm{available}}.
\]

OOM 记录没有被错误地当成“峰值等于卡容量”的普通回归标签。

| 层级 | 数量 | 说明 |
|---|---:|---|
| 本轮已完成作业 | 186 | 152 success + 34 OOM |
| 折叠后的拟合单元 | 156 | 相同物理配置和重复实验先合并 |
| 精确中心 | 112 | 可用于中心回归 |
| OOM 右删失单元 | 30 | 作为下界约束 |
| success/OOM 混合不稳定单元 | 2 | 不作为精确中心 |

## 4. 显存影子模型

### 4.1 模型结构

本次仍然拟合一个共享模型，不按 LoRA、FULL、卡数或 packing 拆成多个路由模型。这些机制以输入特征和交互项进入同一个模型。

模型预测解析显存基准的对数乘性校正：

\[
y_i=\log\frac{M_{\mathrm{obs},i}}{M_{\mathrm{ref},i}},
\qquad
M_{\mathrm{center},i}=M_{\mathrm{ref},i}\exp(\hat y_i).
\]

其中：

- \(M_{\mathrm{ref}}\) 是具有 bytes 量纲的物理解析基准；
- \(M_{\mathrm{obs}}\) 是成功实验测得的单卡 reserved memory 峰值；
- \(\hat y\) 是统一回归模型学到的无量纲校正量。

候选特征族和正则强度只在每个外层训练折内部选择。最终 49 个外层留一来源折全部选择 `unified_shared_interactions`，正则强度 \(\alpha=0.1\)。

### 4.2 泛化结果

#### 嵌套留一来源交叉验证

| 指标 | 结果 |
|---|---:|
| 精确中心数 | 340 |
| 独立来源数 | 49 |
| 来源等权 MAPE | 15.36% |
| 行等权 MAPE | 14.68% |
| Median APE | 10.90% |
| P90 APE | 33.76% |
| 最大 APE | 64.31% |
| 有符号偏差 | +5.05% |
| OOM 右删失约束满足率 | 87.67%（64 / 73） |
| 平均 OOM 下界缺口 | 0.46% |

这里的“来源等权 MAPE”先在每个数据来源内求平均，再对来源求平均，避免样本多的来源主导结果。正偏差表示总体偏高估，但它不能抵消局部配置上的显著低估。

#### 与旧模型及其他诊断基准比较

以下结果来自同一份既有严格跨来源成功诊断集，共 29 个中心、5 个来源。该诊断集以前已经被查看过，因此只能用于比较，不能作为新的前瞻验收集。

| 方法 | 来源等权 MAPE | P90 APE | 解释 |
|---|---:|---:|---|
| 解析基准 | 10.96% | 27.96% | 不做统计校正 |
| 当前 V5 | 15.43% | 40.35% | 当前生产候选的既有输出 |
| Pooled profile 诊断 | 9.61% | 27.01% | 旧的 pooled 特征诊断 |
| 同一模型族，仅旧数据 | 12.69% | 17.98% | 本次收益对照基线 |
| 同一模型族，旧数据 + 本轮数据 | 11.59% | 25.91% | 本次影子模型 |
| 旧 route-specific 诊断 | 10.08% | 25.00% | 仅作历史诊断比较 |

严格比较应使用“同一模型族，仅旧数据”与“旧数据 + 本轮数据”：MAPE 从 12.69% 降至 11.59%，绝对改善 1.11 个百分点，约为 8.7% 的相对改善。新模型仍未超过 pooled profile 和 route-specific 两个已查看诊断结果。

### 4.3 误差分解

| 分组 | 来源等权 MAPE | OOM 约束满足率 | 当前判断 |
|---|---:|---:|---|
| 旧 V5 数据 | 15.18% | 90.70% | 误差仍高 |
| 本轮新数据 | 16.16% | 83.33% | 新域更难 |
| FULL | 12.24% | 82.05% | 中心优于 LoRA，边界仍有漏判风险 |
| LoRA | 16.82% | 94.12% | 中心误差是主要问题 |
| 1 GPU | 13.42% | 45.45% | 当前最明显的容量低估风险 |
| 2 GPU | 15.24% | 94.87% | 右删失约束较稳定 |
| 4 GPU | 16.67% | 95.65% | 中心误差仍高 |

本轮 matched anchor 的 MAPE 为 12.66%，boundary probe 为 16.56%。Critical same-max 诊断只有 2 个精确中心，MAPE 为 37.67%，样本量和误差都表明该区域尚未被可靠描述。

packing 子集在交叉验证中看似只有约 4%–5% MAPE，但目前只覆盖已完成的少量 2-GPU FULL 配置，且剩余 12 个 packing 物理单元不完整。该数字不能外推为 packing 已经解决。

### 4.4 显存侧判断

**经验观察：** 新数据可以改善同一模型族的跨来源平均误差，但改善幅度不足，且 1-GPU OOM 下界满足率很差。

**机制解释：** 一个可能原因是现有解析基准和共享交互项仍未充分描述数据分布尾部、机制与卡数的联合作用。该解释与 Critical same-max 和 1-GPU 结果一致，但当前数据不能证明因果关系。

**工程结论：** 当前既不能只修“放不放行”，也不能认为中心预测准了之后所有问题自然消失。中心误差和低估尾部都需要独立验收。

## 5. 吞吐影子模型

### 5.1 数据准入

本轮 186 条终态观测中：

| 类别 | 数量 | 处理 |
|---|---:|---|
| 进入吞吐拟合器 | 118 | 成功且满足现有准入契约 |
| OOM | 34 | 无吞吐标签，排除 |
| Critical 诊断成功记录 | 16 | 未授权用于吞吐校准，排除 |
| packed 成功记录 | 18 | 现有吞吐契约显式排除 packing effect |

118 条准入记录经过重复实验合并后，为 H800 训练集新增 105 个候选和 29 个场景。H800 训练候选从 238 增至 343，数据集从 6 个增至 13 个，并新增 `qwen3_32b` 支持证据。

18 条 packed 成功记录并非没有采集，而是现有吞吐准入函数 `throughput_admission_reason` 返回 `packing_effect_evidence_excluded`。本次没有绕过该业务规则；进入拟合的 packing 相关记录是 matched-unpacked 对照，不是 packed 本身。

### 5.2 泛化比较

| 验证协议 | 旧模型 | 本次影子模型 | 变化 |
|---|---:|---:|---:|
| H800 既有留出：场景等权 MAPE | 14.98% | 14.95% | -0.03 pp |
| H800 既有留出：P90 APE | 34.22% | 29.46% | -4.75 pp |
| H800 既有留出：pairwise accuracy | 90.41% | 90.85% | +0.44 pp |
| RTX4090 场景 CV：场景等权 MAPE | 13.36% | 14.03% | +0.67 pp |
| 未见模型：场景等权 MAPE | 28.86% | 32.85% | +3.99 pp |
| 未见数据集：场景等权 MAPE | 19.49% | 21.79% | +2.30 pp |

未见数据集验证的候选和场景集合随新增数据发生了变化，因此不能把其差值解释为完全同分布的 A/B 比较。H800 既有留出集保持不变，更适合观察本轮重拟合对原支持域的影响。

**经验观察：** H800 尾部误差下降，但平均误差几乎不变；跨模型和跨数据集指标没有同步改善。

**工程结论：** 本轮吞吐重拟合没有提供足够的一致性证据，不应替换现有模型。

## 6. 当前卡点

1. 显存中心泛化仍弱：嵌套跨来源 MAPE 15.36%，LoRA 和 4-GPU 组更高。
2. 显存低估风险未稳定：总体 OOM 约束满足率 87.67%，1-GPU 仅 45.45%。
3. packing 覆盖不完整：停止时仍有 12 个物理单元缺少完整配对，目前完成子集集中在 2-GPU FULL。
4. Critical same-max 只有 2 个精确中心，无法可靠估计长度分布高阶统计对峰值显存的影响。
5. 吞吐新数据全部属于拟合分区，没有新的 sealed prospective holdout；现有 H800 留出集此前已经被查看过。
6. packed 吞吐记录仍被旧准入契约排除，端到端推荐器尚不能声称学习了 packing 的真实吞吐增益。

## 7. 建议的下一步

1. 暂不恢复剩余 34 个任务，也不发布本次影子模型。
2. 先围绕 1-GPU OOM 约束失败点设计少量边界二分实验，补足 FULL/LoRA、GC on/off 和代表性长度分布，而不是继续均匀扩充已有密集区域。
3. 补齐 packing 的 12 个物理单元时，应保证 packed/unpacked 成对完成，并覆盖当前缺失的卡数与训练类型；否则不要用已完成子集外推。
4. 在模型与特征冻结后，建立一批全新来源的前瞻留出集，同时验收中心 MAPE、P90 APE、OOM 下界满足率和推荐 Top-1 regret。
5. 单独评审 packed 吞吐的准入契约。只有明确允许 packed 数据进入统一吞吐模型，并建立相应的分组留出验证后，才能补齐端到端推荐器的 packing 能力。
