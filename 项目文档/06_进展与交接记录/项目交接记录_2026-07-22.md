## Critical unfinished work

Treat these as correctness work, not optional polish:

1. **Nested tail calibration.** Current center models use an outer global scenario holdout, but conformal residuals are computed on the same outer-training rows used to fit the center. The artifact explicitly carries blocker `conformal_tails_use_same_outer_training_fold_residuals_not_inner_scenario_oof`. Replace this with inner global scenario OOF residuals inside every outer fold. Preserve exact finite-sample ranks and fail closed when fewer than 19 scores are available.

2. **Right-censored memory tail.** Use success residuals as exact events and OOM lower inequalities as right-censored evidence. `calibration_math.py` already includes Kaplan–Meier support. Report statistical P95 identifiability separately from an operational safety upper bound. The training OOM guard must be at least `max(censor_lower, safe_limit + 1) - center`; never invent an OOM peak.

3. **Cohort/evidence uncertainty.** Derive non-negative leave-one-cohort-out and evidence-tier inflation where identifiable. A missing verified anchor must remain a blocker, never an arbitrary multiplier or silent default.

4. **Joint admission and ranking.** The current throughput regret/ranking path does not first filter candidates through the fold’s predicted memory P95. Fix validation so each held-out candidate is admitted only when `predicted_p95 <= 0.95 * actual_capacity`, then rank admitted candidates by throughput lower bound. Regret’s oracle denominator must be the best measured successful candidate whose observed peak also satisfies the 95% line. No predicted-safe candidate when a real safe candidate exists should count as regret 1. A predicted-safe OOM is a safety failure, not merely throughput regret.

5. **Minimum-card/scaling policy.** Validate the smallest safe card count first. A 1→2 or 2→4 recommendation may be made only when the conservative throughput ratio is at least 1.8 and the held-out measured ratio is also at least 1.8. Both endpoints must pass memory admission.

6. **Input and artifact integrity.** The calibrator binds `basis_report_sha256` but should independently validate the basis schema and recomputed digest before fitting. Make report writes atomic, bind implementation/fold membership hashes, reject NaN/Inf, and add mutation/leakage tests. Do not generate a production profile from historical recovery.

7. **Gap report.** After corrected nested joint validation, produce a small machine-readable evidence-gap artifact that names only mechanism-specific missing evidence and prospective acceptance needs. Do not create a new GPU queue automatically. If targeted experiments are truly necessary, make a new schema and a minimal separately approved design.

8. **Documentation and production boundary.** Update `README.md`, `PIPELINE.md`, `EXPERIMENT_DESIGN.md`, and the writable planner design only after final metrics stabilize.
